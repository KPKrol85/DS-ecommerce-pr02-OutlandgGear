## Images and Graphics

- The image pipeline generates variants under [`assets/img/`](assets/img/) from 18 canonical files under `assets/img-src/`, paired by relative path and filename stem. The product and hero files have JPEG, WebP, and AVIF variants. The company images have PNG, WebP, and AVIF variants.
- [`favicon.svg`](assets/fav-icons/favicon.svg) identifies [RealFaviconGenerator](https://realfavicongenerator.net/terms-of-service) as the generator. It and [`logo.svg`](assets/logo/logo.svg) embed byte-identical copies of [`logo.png`](assets/logo/logo.png). The generator's terms allow use of its output and leave responsibility for rights in the input with the user. The raster favicons and manifest icons use the same badge design.
- The [desktop](assets/screenshots/desktop.jpg) and [mobile](assets/screenshots/mobile.jpg) screenshots depict the Outland Gear site and reproduce assets used on the page.

## Development Dependencies

The npm tooling is declared in `devDependencies` in `package.json` and resolved in `package-lock.json`. The production build compiles local CSS and bundles local JavaScript modules. Its esbuild input graph contains only project modules, and its static copy step excludes the npm installation and `assets/img-src/`. The font and icon license files travel with the shipped assets, and the build copies this notice to the production root.
